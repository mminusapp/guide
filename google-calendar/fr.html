Guide de connexion Google Agenda

Présentation

M-Cal utilise le framework EventKit d'iOS. Il vous suffit d'ajouter votre compte Google dans les réglages de l'iPhone pour que vos événements Google Agenda s'affichent automatiquement dans M-Cal.

Étapes de configuration

  1. Ouvrez l'application Réglages sur votre iPhone.
  2. Touchez Apps.
  3. Touchez Calendrier.
  4. Touchez Comptes de calendrier.
  5. Touchez Ajouter un compte, puis sélectionnez Google et connectez-vous. Si votre compte Google est déjà ajouté, touchez le nom du compte.
  6. Vérifiez que Calendriers est activé.

C'est terminé. Ouvrez M-Cal pour voir vos événements Google Agenda.

Calendriers des jours fériés

Vous pouvez ajouter les calendriers de jours fériés de votre région via Google Agenda.

  1. Ouvrez Google Agenda dans votre navigateur.
  2. Cliquez sur le + à côté de « Autres agendas » sur la gauche.
  3. Sélectionnez Parcourir les agendas intéressants.
  4. Dans la catégorie Fêtes nationales, cochez les pays souhaités.

Les calendriers ajoutés seront automatiquement synchronisés avec M-Cal via votre iPhone.

Dépannage

Les événements ne s'affichent pas

Allez dans Réglages > Apps > Calendrier > Comptes de calendrier et vérifiez que Calendriers est activé pour votre compte Google.

La synchronisation prend du temps

La synchronisation avec Google Agenda peut prendre quelques minutes. Tirez l'écran vers le bas dans M-Cal pour actualiser.
